# Данные

Для воспроизведения поместите сюда исходный `customers.csv`: 205 строк и пять столбцов — `customer_id`, `gender`, `age`, `annual_income`, `spending_score`.

[Исходный CSV из материалов работы](https://drive.google.com/file/d/17raI7LN-YR9QBOsjozLvuNPl0UZNP8z4/view). Доступ к внешнему файлу зависит от владельца. Проверенная версия: SHA-256 `48ee08af8e6c2f0148862ad72f6fd4dedce68155faf5845a3ba1ee3c7a35227e`.

Доход указан в тысячах долларов в год; индекс расходов — условная оценка активности от 1 до 100. В файле есть пропуски и значение индекса расходов 120. После его замены на пропуск и удаления строк с пропусками остаются 200 клиентов. Два значения дохода 137 тыс. долларов, отмеченные правилом IQR, сохранены как правдоподобные.

Исходный источник и лицензия именно этой версии набора не установлены. CSV не включён в Git. Произвольный похожий набор Mall Customers не гарантирует точного воспроизведения всех этапов очистки.
