# Прогнозирование добычи газа

Линейная регрессия: RMSE на тестовой выборке 208,98 и R² 0,948; сравниваются полная и сокращённая версии признаков, МНК, градиентный спуск и L2-регуляризация. Первичный EDA проведён до разделения, поэтому test не полностью независим.

## Состав

- `analysis.ipynb` — исследование, подготовка данных, модели и выводы.
- `data/README.md` — размещение исходного CSV.
- `requirements.txt` — зависимости для запуска.

## Запуск

Установите зависимости `pip install -r requirements.txt`, поместите CSV в папку `data` и выполните ячейки ноутбука по порядку.

## Происхождение и ограничения

Проект подготовлен на основе учебной работы. Происхождение набора и условия его публичного распространения ещё не проверены; данные в этот пакет не включены. Результаты воспроизводятся на исходном CSV и одном разбиении, но не подтверждают качество в реальной эксплуатации.
