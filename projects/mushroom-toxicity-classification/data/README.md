# Данные

Для воспроизведения поместите сюда `mushrooms.csv` из исходного набора проекта: 8 124 строки, 14 признаков и целевой столбец `class` (`e` — съедобный, `p` — ядовитый).

В описании исходного материала указан [Mushroom Attributes Dataset на Kaggle](https://www.kaggle.com/datasets/ulrikthygepedersen/mushroom-attributes). Точный CSV проекта содержит дополнительные категориальные признаки; произвольный файл с похожим названием не гарантирует воспроизведение результатов.
