# Портфолио по машинному обучению

Исследовательские проекты с табличными данными: анализ, подготовка признаков, построение моделей и оценка результатов. Проекты основаны на учебных работах и сохраняют ограничения проведённых экспериментов.

## Проекты

| Проект | Задача | Подходы | Результат на исследованном разбиении |
| --- | --- | --- | --- |
| [Прогнозирование добычи газа](projects/well-production-regression/) | Регрессия | МНК, градиентный спуск, L2-регуляризация | RMSE 208,98 и R² 0,948 для линейной модели с полным набором признаков |
| [Прогнозирование оттока клиентов банка](projects/bank-customer-churn/) | Классификация | Логистическая регрессия, полиномиальные признаки, SVM, подбор порога | F1 0,634 и ROC-AUC 0,831 при стандартном пороге для полиномиальной логистической регрессии |
| [Классификация ядовитых грибов](projects/mushroom-toxicity-classification/) | Классификация | Gradient Boosting, CatBoost, кросс-валидация, подбор порога | CatBoost: Recall 0,918 и Accuracy 0,952 на test при пороге 0,5 |

## Как воспроизвести

В папке каждого проекта находятся ноутбук, зависимости и инструкция. Для запуска нужен соответствующий исходный CSV. Данные в репозиторий не включены: их источник и условия распространения пока не подтверждены.

Метрики относятся к конкретным данным и разбиениям. В проектах отдельно описано, как предварительный анализ и повторные сравнения на тестовой выборке ограничивают независимость оценки. Для оценки обобщения требуется новая независимая выборка.
